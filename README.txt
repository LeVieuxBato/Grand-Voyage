GRAND VOYAGE — VERSION AUTONOME
Ouvrir index.html dans un navigateur. Aucun serveur ni dépendance externe.
Les fiches peuples sont reprises des huit PDF fournis. Les aptitudes et étapes viennent du guide de création. Voies, talents et anciens parcours exclus.
Le brouillon est enregistré via localStorage si le navigateur le permet. Pour exporter, valider les catégories, puis choisir Enregistrer au format PDF dans la fenêtre d'impression.
Fichiers : index.html (structure), style.css (design), data.js (catalogue), app.js (navigation et formulaire).
Cette version ne modifie pas les anciens fichiers non disponibles. Faites une copie de votre ancien site avant intégration.
